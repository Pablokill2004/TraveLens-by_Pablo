## Project: TraveLens

Premium travel photo explorer with AI-generated destination guides.

## Stack

- **Next.js 16.3.3** (App Router) + **React 19.2.8** + **TypeScript** strict
- **Tailwind CSS v4** + **shadcn** (base-nova style, Lucide icons)
- **Unsplash API** (photos) + **Google Gemini** (travel plans)
- UI language: **Spanish** (`lang="es"`)

## Architecture

```
src/
├── app/
│   ├── page.tsx                    # Homepage: popular + search + masonry grid
│   ├── destination/[id]/page.tsx   # Server component: fetches photo, renders DestinationView
│   └── api/
│       ├── photos/popular/         # GET ?page= → fetchPopular (3 random cities)
│       ├── photos/related/         # POST → fetchRelated (2-query strategy)
│       ├── photos/route.ts         # GET ?q=&page= → searchDestinations
│       ├── photos/[id]/            # GET → single photo
│       └── ai-plan/                # POST → Gemini TravelPlan
├── services/
│   ├── unsplash.ts                 # Server-only. Text pipeline, fetchPopular, searchDestinations, fetchRelated
│   └── gemini.ts                   # Server-only. @google/generative-ai SDK, TravelPlan output
├── components/
│   ├── features/                   # SearchBar, MasonryGrid, PhotoCard, DestinationView, TravelPlanPanel, SimilarGrid
│   └── ui/                         # shadcn primitives
├── hooks/
│   ├── use-favorites.ts            # localStorage-backed via useSyncExternalStore (cached snapshots)
│   └── use-recent-searches.ts      # localStorage-backed via useSyncExternalStore
└── lib/
    ├── types.ts                    # UnsplashPhoto (with displayTitle/displaySubtitle/cityName), TravelPlan
    └── utils.ts                    # cn() helper
```

## Key Patterns

- **BFF pattern**: All API keys stay server-side. Client fetches `/api/*` routes.
- **Display logic**: Photos have `displayTitle`/`displaySubtitle` computed server-side per mode (`home`/`search`/`related`). Text never contains photo IDs or filenames.
- **fetchPopular**: Fetches from 3 random curated cities in parallel. Each city's photos tagged with city name as `displayTitle`.
- **fetchRelated**: Primary query (location + 3 tags) → fallback (city + "landmark travel") → dedupe by ID, limit 8.
- **SearchBar debounce**: Uses `userInteractedRef` to prevent programmatic `setValue` from triggering search. `callbackRef` prevents debounce re-fires from prop changes.
- **useSyncExternalStore**: `getSnapshot()` caches raw string + parsed result to prevent infinite loops from new array references.

## Environment

Required in `.env.local` (gitignored):
- `UNSPLASH_ACCESS_KEY` — Unsplash API (50 req/hr demo)
- `GEMINI_API_KEY` — Google Gemini API
- `GEMINI_MODEL` — override default `gemini-3-flash-preview`

## Gotchas

- Route handler params are async in Next.js 16: `{ params }: { params: Promise<{ id: string }> }` → must `await params`.
- `server-only` imports in `src/services/` — never import from client components.
- shadcn components use `@base-ui/react` primitives, not Radix. `render` prop for polymorphism, `nativeButton={false}` for non-button elements.
- `AGENTS.md` is auto-generated by `next dev` — edits to the marker block get overwritten.
